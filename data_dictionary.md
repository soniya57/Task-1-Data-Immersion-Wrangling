## Data Dictionary

| Column Name      | Description                         | Data Type |
|------------------|-------------------------------------|-----------|
| customer_id      | Unique customer identifier          | Integer   |
| customer_name    | Name of the customer                | String    |
| gender           | Gender of the customer              | String    |
| date_of_birth    | Customer date of birth              | Date      |
| order_id         | Unique order identifier             | Integer   |
| order_date       | Date of order                       | Date      |
| order_amount     | Amount spent on order               | Float     |
| city             | City of the customer                | String    |
| customer_age     | Age calculated from DOB             | Integer   |
| order_month      | Month when order was placed         | Integer   |
| order_year       | Year when order was placed          | Integer   |
